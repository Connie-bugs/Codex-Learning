# Codex Learning

这是一个用于学习 GitHub、Git 和 Codex 协作开发的个人仓库。

## 目录

- `01-academic-research/`：论文复现、参考文献、数据和研究代码
- `02-codex-learning/`：Codex 探索、功能测试和学习笔记
- `03-life-projects/`：待办事项、个人工具和其他生活类项目

## 工作约定

- 每个具体项目尽量使用独立文件夹，并维护自己的 README。
- 先记录数据来源、运行环境和使用方法，再开始积累代码。
- 不提交密码、API 密钥、个人隐私、未公开数据或未经确认可以传播的论文全文。
